## Production evidence

VectorCraft created original rectangles, ellipses, paths and live text, then exported native documents, SVGs and PNGs. No sample template was reused. The three native files reopened with 20, 23 and 37 objects respectively, without missing fonts, missing glyphs or warnings. The poster spacing was refined after visual inspection. The display SVGs contain outlined text; editable downloads retain live text and native objects.

EffectCraft created an original eight-layer composition using live type, solids and position keyframes on two pause bars. The editable composition is 1200 × 800, four seconds; the web export is H.264 High, 600 × 400, 24fps, 96 frames and no audio. The bars slowly separate and return. Beginning, middle and end frames were inspected, and FilmCraft confirmed encoded media properties.

The source ZIP includes native documents. Their presence does not imply previous client use, tool mastery or independently executed work by Kayk. These are AI-assisted studies created for this redesign.
